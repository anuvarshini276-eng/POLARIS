# Security

Passwords use salted scrypt. JWT secret is supplied through environment or a generated local ignored secret file. Refresh tokens are random, hashed at rest, rotated and revocable. Login rate limits and account lockouts slow guessing. Public registration cannot choose privileged roles. Bearer tokens avoid cookie CSRF; restrictive same-origin CORS, security headers and React escaping protect browser flows. Files have size, extension, structure and MIME checks, random storage names and authorized downloads. ORM bound queries prevent SQL injection. Audit events record sensitive mutations without tokens/passwords. Role changes revoke sessions; last-admin demotion is disallowed. Production requires HTTPS, external secret management, storage backup and deployment-specific limits.
